### 2. GitHub URL Support ⭐

**Implementation:** `src/github.rs` (254 lines)

**What it does:**
- Parses GitHub URLs in multiple formats:
  - Short format: `owner/repo`
  - HTTPS URLs: `https://github.com/owner/repo`
  - SSH URLs: `git@github.com:owner/repo.git`
  - With branches: `owner/repo/tree/branch`
  - With subpaths: `owner/repo/tree/branch/path`
- Clones to temp directory with shallow clone (`--depth 1`)
- Supports private repos with GitHub token (CLI or env var)
- Auto-cleanup after processing

**Verification:**
```bash
$ flat --github octocat/Hello-World --stats
# Successfully clones and analyzes
```

**Features:**
- ✅ Multiple URL format parsing
- ✅ Shallow cloning for speed
- ✅ Temp directory management
- ✅ Token-based private repo support
- ✅ Branch and subpath support
